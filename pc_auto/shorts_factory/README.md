# 쇼츠 공장 (shorts_factory)

집 PC에서 **1080×1920 세로 쇼츠 MP4**를 자동으로 만들고, 유튜브에 자동 업로드하는 폴더입니다.
사진 1장 + 문장 2줄이면 10분 안에 쇼츠 1편이 나옵니다.

## 파일
| 파일 | 역할 |
|---|---|
| `make_shorts.py` | 영상 생성기 (이미지·타이틀·자막·Ken Burns 줌·나레이션·배경음악) |
| `youtube_upload.py` | 유튜브 자동 업로드 (제목·설명·태그·썸네일·고정댓글·예약공개) |
| `쇼츠_생성.bat` | 더블클릭 실행 (사진을 끌어다 놓으면 그 사진으로 시작) |
| `업로드_가이드.txt` | 유튜브 API 최초 설정 안내 (한 번만) |
| `scenes_example.json` | 여러 장면으로 만드는 예시 시나리오 |
| `requirements.txt` | 필요한 파이썬 패키지 |
| `sample_shorts.mp4` | 실제 생성 결과 샘플 (9.3초) |

## 빠른 시작 (3단계)
```bat
:: 1) 최초 1회 설치
python -m pip install -r requirements.txt

:: 2) 영상 만들기 (사진 없이도 가능)
python make_shorts.py --image 상품.jpg --title "이거 모르면 손해" ^
    --subtitle "오늘만 12,900원" --narration "오늘 소개할 상품은..." --badge "오늘의 핫딜"

:: 3) 유튜브 업로드 (설정은 업로드_가이드.txt 참고)
python youtube_upload.py --video shorts_out.mp4 --title "이거 모르면 손해" ^
    --description "링크는 고정댓글" --privacy public --pinned-comment "링크: https://..."
```
`쇼츠_생성.bat` 을 더블클릭하면 질문에 답하는 방식으로도 만들 수 있습니다.

## 자주 쓰는 옵션
- `--theme dark|navy|mint|sunset|white` — 배경 테마
- `--motion in|out|pan` — 줌 방향 (기본 in)
- `--zoom 1.14` — 줌 배율, `--seconds 12` — 길이(나레이션이 있으면 나레이션 길이에 맞춤)
- `--music bgm.mp3` — 배경음악 (볼륨 자동으로 낮게 깔림)
- `--brand "@sy.global"` — 우하단 워터마크
- `--script scenes_example.json` — 여러 장면 이어붙이기(장면마다 나레이션·모션 지정)
- `--font "C:\Windows\Fonts\meiryob.ttc"` — 글꼴 강제 지정 (자동 선택을 끔)

## 글꼴(폰트) — 일본어 자막 □ 깨짐 방지
- 글자에 **가나(일본어)** 가 있으면 일본어 폰트(Meiryo → Yu Gothic → BIZ UD Gothic → MS Gothic 순)를 먼저 씁니다.
  나머지(한글)는 맑은 고딕으로 자동으로 넘어갑니다.
- 폰트 파일의 문자표(cmap)를 직접 읽어 **그 글자를 실제로 그릴 수 있는 폰트만** 고르고,
  한 폰트에 없는 글자는 **글자 단위로 다음 폰트에 넘겨** 그립니다(예: 맑은 고딕에 없는 장음 `ー`).
- 실행하면 `[폰트] JP 글자 → meiryo.ttc, ...` 처럼 어느 폰트를 골랐는지 한 줄 찍어 줍니다.
  `[폰트 경고] 그릴 수 없는 글자 …` 가 나오면 그 글자(주로 이모지)는 뺀다.
- 일본어 폰트가 하나도 없으면: 설정 → 시스템 → 선택적 기능 → **일본어 보충 글꼴** 추가.

## 어떻게 동작하나
1. 배경: 사진을 1080×1920로 꽉 채워 자르고, 글자 영역(위/아래)만 부드럽게 어둡게 처리
   → 어떤 사진이 와도 흰 글씨가 읽힙니다.
2. 글자: 상단 후킹 타이틀(자동 줄바꿈·자동 크기 조절·그림자) + 하단 자막 박스 + 배지.
3. 움직임: ffmpeg `zoompan` 으로 천천히 확대/축소(2배 해상도에서 계산해 계단현상 최소화).
4. 소리: `edge-tts` 한국어 음성(무료). 인터넷이 없거나 실패하면 **무음으로 자동 폴백**.
5. 출력: H.264 / yuv420p / 30fps / AAC 128k / `+faststart` → 유튜브·릴스·틱톡 모두 호환.

## 저작권·정책
- 사진·음원은 본인이 촬영/보유한 것 또는 사용 허락된 것만 넣으세요.
- 유튜브 쇼츠는 세로 60초 이하일 때 자동 분류됩니다(제목·설명에 `#Shorts` 자동 첨부).
- 업로드 API 할당량은 하루 6편까지입니다(업로드 1건 1,600유닛 / 하루 10,000유닛).
